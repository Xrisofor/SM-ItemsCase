# Items Case / RU

![Mod Preview](https://github.com/Xrisofor/SM-ItemsCase/blob/main/preview.jpg?raw=true)

**Items Case** добавляет интерактивные кейсы с полноценной рулеткой предметов - совсем как в классических кейс-открытиях.

# Как получить в режиме Выживания?
Чтобы воспользоваться Items Case, найдите его в одном из следующих мест:

- [Modded Craftbot Recipes](https://steamcommunity.com/sharedfiles/filedetails/?id=2816900681) - кейсы можно купить в Mininghub Trader.
- [Fant Mod 3 Custom Gamemode](https://steamcommunity.com/sharedfiles/filedetails/?id=3772903275) - кейсы можно купить в Mininghub Trader.
- [FreeBuild Survival](https://steamcommunity.com/sharedfiles/filedetails/?id=3774231932) - кейсы можно купить в Mininghub Trader.

Не можете найти? Убедитесь, что установлена одна из указанных выше кастомных игр, а также Items Case выбран в списке модов вместе с [Mod Database](https://steamcommunity.com/workshop/filedetails/?id=2504530003).

# Как это работает
 
Внутри кейса - барабан со случайными предметами. Взаимодействуйте с кейсом, чтобы открыть окно с рулеткой, и нажмите кнопку открытия. Барабан прокрутится и остановится на одном предмете - именно он попадёт к вам в инвентарь (или выпадет на землю, если инвентарь полон). После открытия кейс уничтожается - он одноразовый.
 
Какой предмет выпадет, решает **сервер** ещё до начала анимации: клиент только красиво прокручивает барабан до заранее определённого сервером результата, поэтому повлиять на исход со стороны клиента невозможно.

## Как считается редкость
 
Редкость предмета не прописана вручную (за редкими исключениями, см. ниже), а вычисляется:
 
- Если у предмета есть рецепт крафта (Craftbot, Portable Craftbot, Mechanic Station, Refinery, Farmer Hideout и другие) - его стоимость рекурсивно раскладывается по ингредиентам вплоть до сырья.
- Если рецепта нет - стоимость считается по физическим характеристикам: объём формы и материал (металл, электроника, стекло, дерево, пластик, резина и т.д. - у каждого материала свой множитель ценности).
- Блоки получают редкость по их игровому рейтингу прочности: чем прочнее блок, тем он реже.
- Инструменты всегда попадают в категорию «Эпический».
- Остальные предметы сортируются по вычисленной стоимости и делятся на группы по процентилям: 45% самых дешёвых - Обычные, следующие 27% - Необычные, 18% - Редкие, 7.8% - Эпические, 2% - Легендарные, 0.2% самых дорогих - Мифические.
- Для отдельных уникальных предметов (украшения, особые ресурсы, некоторые декоративные / квестовые вещи) редкость закреплена вручную и в общий расчёт не попадает.

## Шанс выпадения
 
Шанс каждой редкости - это её вес (45 / 27 / 18 / 7.8 / 2 / 0.2), нормализованный среди тех редкостей, что разрешены именно в этом кейсе. Поэтому у разных видов кейсов разные проценты:
 
| Редкость | Кейс с предметами (мусор) | Кейс с предметами | Специальный кейс с предметами |
| :--- | :---: | :---: | :---: |
| ⚪ Обычный | 62.5% | - | - |
| 🟢 Необычный | 37.5% | - | - |
| 🔵 Редкий | - | 64.3% | - |
| 🟣 Эпический | - | 27.9% | 78% |
| 🟠 Легендарный | - | 7.1% | 20% |
| 🌈 Мифический | - | 0.7% | 2% |
